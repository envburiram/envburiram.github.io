# รายงาน PM2.5 จังหวัดบุรีรัมย์ (Google Apps Script)

ดึงค่า PM2.5 รายอำเภอจาก GISTDA และค่าจากสถานีตรวจวัด air4thai (บุรีรัมย์, นครราชสีมา, ชัยภูมิ, สุรินทร์)
แล้วสร้างรูปแผนที่จาก Google Slides ต้นแบบ บันทึกลง Google Sheets และส่งอีเมลรายงาน

## การติดตั้ง

1. คัดลอก `Code.gs` ไปวางในโปรเจกต์ Apps Script
2. Project Settings > Script properties เพิ่มค่าต่อไปนี้

   | Key | ค่า |
   | --- | --- |
   | `SPREADSHEET_ID` | ID ของ Google Sheets ที่บันทึกข้อมูล |
   | `SLIDE_ID` | ID ของ Google Slides ต้นแบบแผนที่ |
   | `FOLDER_ID` | ID ของโฟลเดอร์ที่เก็บรูปแผนที่ |
   | `NOTIFY_EMAIL` | อีเมลผู้รับรายงาน (หลายคนคั่นด้วย `,`) |

3. (แนะนำ) Project Settings > เปิด "Show appsscript.json" แล้วใช้ค่าจาก `appsscript.json`
   เพื่อกำหนด time zone เป็น `Asia/Bangkok` และจำกัดสิทธิ์ (OAuth scopes) เท่าที่ใช้จริง
   — ถ้าโปรเจกต์มีไฟล์อื่นที่ใช้บริการอื่นด้วย ต้องเพิ่ม scope ของบริการนั้นเอง
4. รัน `getDataPM25` หนึ่งครั้งเพื่ออนุญาตสิทธิ์ แล้วตั้ง time-driven trigger ตามต้องการ

ลำดับชีตกำหนดไว้ที่ `STATION_BR` / `OTHER_STATIONS` (ชีตที่ 1 = นครราชสีมา, 2 = ชัยภูมิ, 3 = บุรีรัมย์, 4 = สุรินทร์)
สามารถเปลี่ยนค่า `sheet` เป็นชื่อชีตแทนลำดับได้

## สิ่งที่แก้จากโค้ดเดิม

### ช่องโหว่

| ปัญหา | การแก้ไข |
| --- | --- |
| `console.log(Options_jpeg)` พิมพ์ OAuth access token ลง log | ลบออก |
| ดึงข้อมูล air4thai ผ่าน `http://` (ข้อมูลถูกดักแก้ระหว่างทางได้) | เปลี่ยนเป็น `https://` |
| นำข้อความจาก API ไปต่อเป็น HTML ในอีเมลโดยไม่ escape (HTML injection) | escape ทุกค่า |
| บันทึกข้อความจาก API ลงชีตตรง ๆ (formula injection เช่น `=IMPORTXML(...)`) | `appendRowSafe_` ใส่ `'` นำหน้าค่าที่ขึ้นต้นด้วย `= + - @` |
| แชร์รูปแบบ `Access.ANYONE` (สาธารณะ ค้นหาเจอได้) | เปลี่ยนเป็น `ANYONE_WITH_LINK` |
| ID ไฟล์และอีเมลผู้รับเขียนไว้ในโค้ด | ย้ายไปเก็บใน Script properties |

### บั๊ก

| ปัญหา | การแก้ไข |
| --- | --- |
| air4thai ส่ง `-1` เมื่อไม่มีข้อมูล แต่โค้ดแปลงเป็น `"<1"` และ `detail_` รายงานว่า "ดีมาก (สีฟ้า)" | ถือเป็น "ไม่มีข้อมูล" ไม่รายงานว่าอากาศดี |
| ถ้าขั้นตอนใดหลัง `makeCopy` ล้มเหลว สำเนาสไลด์จะค้างอยู่ใน Drive ทุกรอบ | ลบสำเนาใน `finally` |
| ใช้ `Slides.getObjectId()` หลัง `saveAndClose()` | อ่าน page id ก่อนปิด |
| try/catch ครอบทั้งลูป อำเภอเดียวที่ค่าเป็น `null` ทำให้อำเภอที่เหลือหายหมด | ข้ามเฉพาะแถวที่ไม่สมบูรณ์ |
| `pm25Avg24hr.toFixed` พังถ้า API ส่งค่าเป็นข้อความ | แปลงด้วย `Number()` ก่อน |
| shape ID ในสไลด์ไม่ตรงทำให้ `ObjectId[id]` เป็น `undefined` แล้วงานทั้งหมด (ชีต, อีเมล) ล้ม | ตรวจก่อนใช้ และ log เตือน |
| อำเภอที่ไม่มีข้อมูลยังเหลือ `{n}` บนรูป | แทนที่ด้วย `-` |
| เกณฑ์สีบนแผนที่ (`>= 75.1`) กับข้อความ (`> 75.0`) แยกกันคนละที่ | ใช้ `detail_` ที่เดียว |
| `new Date("yyyy-MM-dd")` ตีความเป็น UTC วันที่อาจเพี้ยนไป 1 วันตาม time zone ของสคริปต์ | แยกตัวเลขจากข้อความ และใช้ `Asia/Bangkok` ชัดเจน |
| ขึ้นบรรทัดใหม่ (`\n`) ในคำแนะนำไม่แสดงในอีเมล HTML | แปลงเป็น `<br>` |
| `Logger.log(error.message)` กลืน error ทั้งหมด การทำงานขึ้นว่าสำเร็จเสมอ | log พร้อม stack และ throw สรุปตอนท้าย ให้ trigger แจ้งเตือนเมื่อล้มเหลว |
| ขั้นตอนหนึ่งล้ม (เช่นส่งออกรูป) ทำให้ไม่บันทึกชีต/ไม่ส่งอีเมล | แยกแต่ละขั้นตอนให้ทำงานต่อได้ |
| ใช้ `Sheet[0..3]` ตามลำดับแท็บอย่างเดียว | รองรับชื่อชีต |
| trigger ทำงานซ้อนกันได้ ทำให้แถว/อีเมลซ้ำ | ใช้ `LockService` |
| ไม่ตรวจ HTTP status ก่อน `JSON.parse` | ตรวจ status code |
| `PM₂₅` อ่านว่า PM25 | เปลี่ยนเป็น `PM2.5` |
| โค้ดของ 4 สถานีคัดลอกซ้ำกัน | รวมเป็น `fetchStation_` |
